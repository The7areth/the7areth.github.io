01 / Machine learning↗

ChurnLens

From customer data to a working prediction service.

An end-to-end churn study that turns reproducible model comparison into a FastAPI service and a Streamlit application.

Python · scikit-learn · FastAPI · Streamlit
Explore the project +

The question

Which customers should a retention team review first?

The approach

Compare Logistic Regression, Random Forest and XGBoost using the same train, validation and test split. Persist preprocessing with the model, select the operating threshold on validation data, and share inference between the API and interface.

The evidence

The selected logistic regression model reaches 0.832 test ROC-AUC on the IBM Telco sample dataset. At the served threshold it finds 199 of 374 churners, with 125 false positives.

Current scope

A held-out benchmark on a fictional sample dataset, not a measured business outcome. Real deployment needs representative data and a cost-aware intervention policy.

03 / Applied AI↗

AI Support Copilot

Support suggestions with sources you can inspect.

A support triage prototype that retrieves runbooks, cites its evidence and makes escalation an explicit decision.

Python · FastAPI · TF-IDF · Ollama
Explore the project +

The question

Can a support assistant make useful suggestions without hiding where they came from?

The approach

Retrieve with TF-IDF, inherit the supported runbook category, and apply escalation rules. Optional local generation adds a structured summary; invalid output falls back to cited steps.

The evidence

Includes reproducible synthetic regression checks and a narrower external BANKING77 duplicate-charge evaluation that reveals retrieval weaknesses.

Current scope

A human-reviewed prototype. It sends no messages or remediation commands. Synthetic evaluation scores are not real-world accuracy, and live-model answer quality remains unevaluated.

04 / Machine learning↗

Hotel Cancellation ML

Reservation risk, with the tradeoffs in view.

A chronological study of hotel cancellations with calibrated probabilities, baseline comparisons and review-threshold analysis.

Python · scikit-learn · Pandas · FastAPI
Explore the project +

The question

Which reservations deserve closer review before a cancellation disrupts planning?

The approach

Separate training, validation, calibration and test cohorts chronologically. Select a random forest by validation average precision, calibrate its probabilities, and expose the decision tradeoff through a small API demo.

The evidence

The final test cohort yields 0.766 ROC-AUC and 0.716 average precision. A lower review threshold raises cancellation recall while also producing substantial false alerts.

Current scope

Retrospective near-arrival snapshots from two historical hotels. Results do not validate initial-booking predictions, current hotel performance or revenue savings.

05 / Full-stack application↗

Runline

Understand the run. See the evidence.

A private running workspace for editable imports, session comparisons, training history and transparent race scenarios.

React · TypeScript · Workers · D1 · R2
Explore the project +

The question

How can a runner understand their history without opaque scores?

The approach

Combine activity imports, browser OCR and recovery check-ins. Compare similar-distance runs on a consistent time basis, exclude future activities from historical analysis, and show the inputs behind each finding.

The evidence

Deterministic calculations with regression coverage for history comparisons, file parsing, unit conversion and bounded public-link reading.

Current scope

Uses a deterministic evidence engine, not an LLM or trained forecasting model. Race scenarios are formula-based; personal running records remain private.

06 / Applied AI↗

Travel Operations Agent

The agent proposes. A person approves.

A bounded tool-calling prototype that turns a trip request into a priced draft and connects it to an operations workflow.

Python · FastAPI · SQLite · Ollama
Explore the project +

The question

How can an agent help prepare a travel offer while keeping calculations and approval explicit?

The approach

Constrain tool calls, validate arguments and calculate prices in integer cents. Bind review to a stored draft, then export an approved PDF or import an operations draft through a separate adapter.

The evidence

The repository records 12 exact-price demo scenarios and an HTTP create/read round trip into the public operations demo.

Current scope

Fictional catalog and rates. No live availability, reservations or payments. The local model integration exists, but live-model quality still needs evaluation.
